# Custom Sorting Image Uploader

A React Native (Expo) app that watches folders on your Android device and automatically uploads new images to your AWS S3 server.

## Features

- **Folder Watching**: Select multiple folders/albums to monitor for new images
- **Automatic Upload**: New images are automatically detected and uploaded
- **Image Optimization**: Images are resized and compressed to WebP format before upload
- **Notifications**: Get notified when uploads start, complete, or fail
- **Retry Logic**: Failed uploads are automatically retried
- **Activity Logs**: View detailed logs of all upload activity
- **Auto-Delete**: Successfully uploaded images are removed from the device

## Requirements

- Android 12 (API 31) or later
- Server with the upload API endpoint (compatible with custom-sorting-image-viewer)

## Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure the App

Before using the app, you need to configure:

1. **Server URL**: The URL of your server that provides the presigned upload URLs
   - Default API endpoint: `POST /api/cloudfront/upload-url`
   - The server should return `{ uploadUrl: string, key: string }`

2. **Device ID**: A unique identifier for this device (auto-generated by default)

3. **Image Settings**:
   - Max Width: 300px (default)
   - Max Height: 300px (default)
   - Quality: 20% (default)

### 3. Run in Development

```bash
# Start Expo development server
npx expo start

# Run on Android device/emulator
npx expo run:android
```

### 4. Build for Production

```bash
# Build APK for Android
npx expo build:android -t apk

# Or use EAS Build (recommended)
npx eas build --platform android
```

## Usage

1. **Grant Permissions**: Allow access to media library and notifications when prompted
2. **Configure Server**: Tap the settings icon (⚙️) and enter your server URL
3. **Add Folders**: Tap "Add Folder" to select albums/folders to watch
4. **Start Watching**: Tap "Start Watching" to begin monitoring for new images
5. **View Logs**: Tap "View Logs" to see upload activity

## Server API Compatibility

This app is designed to work with the `custom-sorting-image-viewer` server. The upload flow:

1. App requests presigned URL: `POST /api/cloudfront/upload-url`
   ```json
   {
     "filename": "image.webp",
     "contentType": "image/webp",
     "deviceId": "device_123"
   }
   ```

2. Server responds with:
   ```json
   {
     "uploadUrl": "https://s3.amazonaws.com/...",
     "key": "device_123/1234567890-image.webp"
   }
   ```

3. App uploads directly to S3 using the presigned URL

## Permissions Required

- **READ_EXTERNAL_STORAGE**: Access photos on device
- **WRITE_EXTERNAL_STORAGE**: Delete photos after upload
- **READ_MEDIA_IMAGES**: Access images (Android 13+)
- **POST_NOTIFICATIONS**: Show upload notifications
- **INTERNET**: Upload images to server

## Troubleshooting

### Uploads Failing
- Check your server URL is correct
- Verify the server is running and accessible
- Check the activity logs for error details

### Folders Not Showing
- Ensure media library permission is granted
- The app uses MediaLibrary albums, not file system folders

### Images Not Being Detected
- The watcher checks every 10 seconds
- Only image files (jpg, png, gif, webp, heic) are detected
